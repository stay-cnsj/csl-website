# 网站内容维护说明

## 当前内容来源

《华科网页制作.docx》提供了方向名称、两段介绍，以及一张研究方向架构图。网页按这些材料组织为首页、研究方向、研究架构与关于实验室四个页面。

方向中文名称为“认知大模型与数据智能”，英文名称为“Cognitive Large Models and Data Intelligence”。原文表述为“该方向拟下设计算机科学实验室（Computer Science Lab，简称 CSL），由曾志刚教授担任实验室负责人”。在收到新的正式材料之前，保留“拟下设”的状态，不将实验室描述为已成立。

2026-09-25 根据《内容.docx》更新研究方向页面，页面标题采用新稿中的“认知大模型与数据智能体”，四个主题为“智能体训练与优化”“可解释性与安全可信”“具身智能与世界模型”“AI4S与科学发现”。介绍、研究重点、关键词和交叉应用均依据新稿，校正英文拼写 Comupter 为 Computer。首页和实验室基础信息仍沿用已确认的上一版材料。

研究架构页增加论文与研究成果区域，按提供的图片准备左右交错的图文布局。根据用户后续明确要求，先发布两项标注“占位示例”的论文展示内容，主题取自研究方向，配图为原创流程示意，没有虚构作者、期刊、年份或论文链接。2026-09-28 改为图片、标题、作者、Abstract、链接五项结构，内容维护在 `public/content/publications.json`，并新增 `/editor/` 网页编辑器。保留原有研究架构图与说明。维护方法见 [研究成果维护](publications.md)。参考图片中的论文只用作版式参考，不作为本实验室成果。

2026-09-28 根据用户提供的 `CSL-web/` 中 13 份个人 DOCX 和层级截图，在关于实验室页增加成员卡片：负责人 1 人、博后 2 人、硕士 8 人、RA 2 人。姓名、身份、简介、研究方向与 6 个主页链接来自各自文档，分组和顺序遵循截图。邵天宇归 RA 组并保留原文“24级本科生”身份。原有实验室介绍保留。

原文末尾的“更多信息请访问 xxx”尚无真实链接，网站没有将其作为可点击链接发布。文件名中的“华科”也不足以确定网站应该展示的正式学校、学院或研究机构名称。

## 图片与视觉素材

- 研究架构图已按用户要求替换为 `CSL_Research_Overview.svg`，网站文件为 `public/images/research-framework.svg`，2560 × 1600。原图完整保留，可放大查看；研究架构整体排列在论文成果上方。早期 Word 中提取的 PNG 不再用于页面展示。
- 首页及内页页头使用内置 ImageGen 生成的原创纤维脑部概念图 `public/images/cognitive-brain.png`（1448 × 1086），用于认知智能概念示意，并非真实研究结果。提示词与来源见 `docs/asset-sources.md`。
- 两项论文占位配图为 `public/images/publications/` 下的原创 SVG 流程图（1200 × 760），图内标注“示意配图 · 论文占位”，并非论文原图或实验结果。
- 成员照片为上述 13 份 DOCX 中的原始内嵌照片，保存于 `public/images/people/`。黄诗颖照片的归档 CRC 元数据异常，已恢复图像并完成解码与视觉检查。没有提供实验室实景、正式机构 Logo 或可用的新闻照片。
- MIT EvLab 仅作为视觉排版参考，不能把其人员、新闻、论文、Logo 或身份信息写成本实验室的内容。

## 更新步骤

1. 将经确认的事实整理到 `app/data/site.ts`，保持术语与中英文名称一致。
2. 将要公开的图片放到 `public/images/`，使用清晰文件名，并更新页面的图片尺寸与替代文字。
3. 在本地检查文字、移动端排版、导航和图片放大行为。
4. 运行 `npm run typecheck` 和 `npm run generate`，通过后提交并推送。

原始 Word 文件与提取中间文件仅保存在本地参考目录，已由 `.gitignore` 排除。只有经选用的网页文字和 `public/` 下的素材会进入发布内容。
